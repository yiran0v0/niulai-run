# 牛来·梦境狂奔（Niu Lai Run）

一个致敬 2026 年国产动画电影[《牛来》](https://zh.wikipedia.org/wiki/%E7%89%9B%E6%9D%A5)（信雨萌导演）的 3D 网页跑酷冒险游戏。

电影由母子二人耗时五年、"纯手工、不用 AI"制作，以"粗糙到极致"的低多边形画风与唯一的水墨海报意外出圈。本游戏以浏览器实时渲染向这份"手搓"精神致敬：

- **水墨海报风**的天空渐变、三层晕染远山、淡红日与流云
- **"用多边形搭砖头"式**低多边形低模（flatShading）角色与景物
- 剧情意象入局：主角小牛犊「牛来」、见证者云雀「云玎」、反派狼群、灵蛇语录

## 玩法

| 按键 | 动作 |
|---|---|
| ← → / A D | 左右换道 |
| ↑ / W / 空格 | 跳跃 |
| ↓ / S | 滑铲（悬垂树枝必须滑铲通过） |
| 触屏 | 滑动手势同样可玩 |

- 躲开木桩、巨石、木栏、狼群与悬枝
- 收集草料捆（+50 分），铜铃有专属音效
- 速度随里程持续提升，得分 = 里程 + 草料×50

## 运行

```bash
cd niulai-run
python3 -m http.server 8790
# 打开 http://127.0.0.1:8790/index.html
```

无构建、无依赖安装（Three.js r170 已本地化于 `vendor/`），支持移动端。

## 开发方式：Loop Engineering

每个功能模块都在真实浏览器（headless Chrome）中验证后再进入下一个：

```bash
./verify.sh m7 "?t=1"   # 截图 + 控制台日志 + 自动化自检
```

自检模式（`?t=1`）会隐藏标题屏、自动开局，并在页面内运行"无渲染模拟"：
跳跃 / 滑铲 / 换道 / 障碍碰撞 / 收集判定 / 死亡重开，全部断言通过、控制台零报错才算 pass。

模块与对应验证产物（`shots/`）：
M1 场景渲染 → M2 主角建模（含侧视朝向验证）→ M3 无尽赛道（500m 快进回收）→ M4 障碍/收集（对象池）→ M5 操控物理 → M6 状态机/HUD → M7 电影感润色（音效/粒子/云/镜头）→ M8 全量回归（普通模式 + t 模式×3）。

## 结构

```
index.html          界面/HUD/水墨风格 UI
js/config.js        全局参数与"手搓"调色板
js/world.js         渲染基础：水墨天空/远山/云/雾/光照
js/ox.js            主角牛来：程序化低模 + 跑/跳/滑铲动画
js/track.js         无尽赛道滚动带 + 路边景物池
js/items.js         障碍与收集物：对象池 + 模式化生成（保证有活路）
js/player.js        操控与 AABB 碰撞（键盘 + 触摸）
js/game.js          状态机/计分/云雀伴随/镜头语言
js/audio.js         WebAudio 合成音效（零素材）
js/particles.js     蹄下扬尘粒子
vendor/             Three.js r170（本地化）
verify.sh           浏览器验证脚本（Loop Engineering）
```
